## API

C API for the [SwissTable hash table generator](https://github.com/yourusername/swisstable).

This document provides a description of the functions and types in the swiss.h source file.

It's recommended to first read the more general overview in the project [README](https://github.com/yourusername/swisstable).

Below is a complete list of all functions generated by SwissTable. 
The "sw" namespace is used as a placeholder. This is configurable by the developer
using SWISS_NAME.

```c
#define SWISS_NAME sw
```

Every SwissTable provides the following functions and types.

## Types

```c
/// The hash table type
typedef struct sw_table {
    sw_entry *entries;      // Array of entries
    uint8_t *ctrl;          // Control bytes for probing
    uint64_t bloom[4];      // 256-bit Bloom filter
    uint32_t capacity;      // Allocated slots (power of 2)
    uint32_t count;         // Number of active entries
    uint64_t generation;    // Incremented on each rebuild
} sw_table;

/// The entry type (returned by find/add operations)
typedef struct sw_entry {
    SWISS_KEY_TYPE key;     // The entry key (owned by table)
    uint64_t hash;          // Cached hash value
    SWISS_VALUE_TYPE value; // The entry value
    unsigned flags;         // Entry flags
} sw_entry;
```

## Lifecycle

```c
/// Initialize a new empty table
/// The table should be zeroed before first use, or use sw_init()
void sw_init(sw_table *table);

/// Free all resources associated with the table
/// This frees all keys using SWISS_FREE_KEY and all internal memory
void sw_free(sw_table *table);

/// Rebuild the table (compaction after heavy deletes)
/// This removes deleted slots and may shrink the table
void sw_rebuild_cache(sw_table *table);
```

## Basic Operations

```c
/// Find an entry by key
/// Returns a pointer to the entry if found, NULL otherwise
/// Uses Bloom filter for fast negative lookups
sw_entry* sw_find(sw_table *table, SWISS_KEY_TYPE key);

/// Insert or update an entry
/// If the key already exists, updates the value and returns the existing entry
/// Otherwise, creates a new entry and returns it
/// The 'flags' parameter is stored in the entry
sw_entry* sw_add(sw_table *table, SWISS_KEY_TYPE key, SWISS_VALUE_TYPE value, unsigned flags);

/// Delete an entry by key
/// Returns true if an entry was deleted, false if not found
bool sw_delete(sw_table *table, SWISS_KEY_TYPE key);
```

## Helper Functions

The following helper functions are available for use in your macros:

```c
/// FNV-1a 64-bit hash for strings (case-sensitive)
uint64_t hash_string(const char *str);

/// FNV-1a 64-bit hash for strings (case-insensitive)
uint64_t hash_string_case_insensitive(const char *str);

/// Extract 8-bit fingerprint from 64-bit hash
/// Ensures result is never 0x00 (empty) or 0x80 (deleted)
uint8_t entry_fingerprint(uint64_t h);

/// Add hash to Bloom filter
void bloom_add(uint64_t bloom[4], uint64_t h);

/// Check if Bloom filter may contain hash
/// Returns false if definitely not present, true if maybe present
bool bloom_may_contain(const uint64_t bloom[4], uint64_t h);
```

## Example Usage

### Basic Operations

```c
#include <stdio.h>
#include <stdint.h>
#include <stdlib.h>
#include <string.h>

static inline const char* str_dup(const char *str) {
    if (!str) return NULL;
    size_t len = strlen(str);
    char *copy = malloc(len + 1);
    if (copy) memcpy(copy, str, len + 1);
    return copy;
}

typedef struct { uint32_t id; } value_t;

#define SWISS_NAME mymap
#define SWISS_KEY_TYPE const char*
#define SWISS_VALUE_TYPE value_t
#define SWISS_HASH(k) hash_string(k)
#define SWISS_EQ(k1,k2) (!strcmp((k1),(k2)))
#define SWISS_DUP_KEY(k) str_dup(k)
#define SWISS_FREE_KEY(k) free((void*)(k))
#include "swiss.h"

int main() {
    mymap_table table;
    mymap_init(&table);
    
    // Add entries
    mymap_add(&table, "key1", (value_t){1}, 0);
    mymap_add(&table, "key2", (value_t){2}, 0);
    
    // Find entry
    mymap_entry *e = mymap_find(&table, "key1");
    if (e) {
        printf("Found: %s -> %u\n", e->key, e->value.id);
    }
    
    // Update existing entry
    mymap_add(&table, "key1", (value_t){10}, 0);  // Updates value to 10
    
    // Delete entry
    mymap_delete(&table, "key2");
    
    // Clean up
    mymap_free(&table);
    return 0;
}
```

### Multiple Tables in Same File

```c
// First table: String -> Int
#define SWISS_NAME strtab
#define SWISS_KEY_TYPE const char*
#define SWISS_VALUE_TYPE int
#define SWISS_HASH(k) hash_string(k)
#define SWISS_EQ(k1,k2) (!strcmp((k1),(k2)))
#define SWISS_DUP_KEY(k) str_dup(k)
#define SWISS_FREE_KEY(k) free((void*)(k))
#include "swiss.h"

// Second table: Int -> Pointer
#define SWISS_NAME intptr
#define SWISS_KEY_TYPE uint64_t
#define SWISS_VALUE_TYPE void*
#define SWISS_HASH(k) (k)
#define SWISS_EQ(k1,k2) ((k1)==(k2))
#define SWISS_DUP_KEY(k) (k)
#define SWISS_FREE_KEY(k) ((void)0)
#include "swiss.h"

int main() {
    strtab_table st;
    strtab_init(&st);
    strtab_add(&st, "hello", 42, 0);
    
    intptr_table it;
    intptr_init(&it);
    intptr_add(&it, 12345, (void*)0xdeadbeef, 0);
    
    strtab_free(&st);
    intptr_free(&it);
    return 0;
}
```

## Configuration Reference

### Required Macros

All of the following must be defined before including swiss.h:

| Macro | Purpose | Example |
|-------|---------|---------|
| `SWISS_NAME` | Namespace prefix | `symtab` |
| `SWISS_KEY_TYPE` | Type of keys | `const char*` or `uint64_t` |
| `SWISS_VALUE_TYPE` | Type of values | `struct { int id; }` |
| `SWISS_HASH(k)` | Hash function | `hash_string(k)` |
| `SWISS_EQ(k1,k2)` | Equality check | `(!strcmp((k1),(k2)))` |
| `SWISS_DUP_KEY(k)` | Key duplication | `str_dup(k)` or `(k)` |
| `SWISS_FREE_KEY(k)` | Key cleanup | `free((void*)(k))` or `((void)0)` |

### Optional Macros

| Macro | Default | Purpose |
|-------|---------|---------|
| `SWISS_ALLOC_MALLOC(sz)` | `malloc(sz)` | Custom malloc |
| `SWISS_ALLOC_CALLOC(n,sz)` | `calloc(n,sz)` | Custom calloc |
| `SWISS_ALLOC_FREE(p)` | `free(p)` | Custom free |

## Table Fields

The `sw_table` struct provides these public fields:

```c
sw_table table;
sw_init(&table);

// Read-only fields (do not modify directly)
table.capacity;     // Current allocated capacity (power of 2)
table.count;        // Number of active entries
table.generation;   // Incremented on each resize/rebuild
table.bloom;        // Bloom filter array (4 uint64_t = 256 bits)
```

## Entry Fields

The `sw_entry` struct provides these fields:

```c
sw_entry *e = sw_find(&table, key);
if (e) {
    e->key;      // The entry key (read-only, owned by table)
    e->hash;     // Cached hash value
    e->value;    // The entry value (read/write)
    e->flags;    // Entry flags (read/write)
}
```

## Implementation Notes

### Memory Management

- Keys are duplicated using `SWISS_DUP_KEY` when inserted
- Keys are freed using `SWISS_FREE_KEY` when entries are deleted or table is freed
- Values are copied by value (use pointers if values need heap allocation)

### Hash Collisions

- SwissTable uses open addressing with linear probing
- 8-bit fingerprints enable fast rejection of non-matching keys during probes
- The Bloom filter provides O(1) negative lookups for missing keys

### Resizing

- Table automatically grows when load factor exceeds 0.5
- Capacity always doubles and remains a power of 2
- The `generation` counter increments on each resize

### Thread Safety

- SwissTable operations are not thread-safe
- External synchronization is required for concurrent access
